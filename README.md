# COMP237: Advanced Java Programming (Fall 2026)

This repository contains my coursework, labs, and projects for the COMP237 Java Programming course, focusing on building scalable, structured, and efficient software.

## 🛠️ Core Concepts Covered
- Object-Oriented Programming (OOP): Inheritance, Polymorphism, Encapsulation, and Abstraction.
- Java Architecture: Collections Framework, Exception Handling, and File I/O.
- Advanced Mechanics: Multithreading, Concurrency, and Stream APIs.
- Design Patterns: Implementing clean, reusable software design practices.
